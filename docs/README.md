# 職務経歴書

## 意欲・興味

- 一次産業・食品関連分野とITの融合による社会的価値創造に注力
- 栄養分野の専門知識とIT技術を活かし、食事管理や健康促進を支援するサービス開発を目指す
- プロダクトマネジメントと開発エンジニアリングを横断した上流工程への関与に強い関心（要件定義・設計・アーキテクチャ判断など）
- 持続可能なシステム設計・チーム運営に対する長期的視点を重視
- 新技術の習得に積極的で、学習した知識を即座に実務へ適用する行動力

- React Native・Next.js を用いたモバイルアプリおよびWeb管理画面の設計・開発を主導
- AWS（Lambda, API Gateway, RDS, S3）および Firebase を活用したスケーラブルなサーバーレスアーキテクチャ設計・構築
- CloudFormation 中心の構成管理を CDK へ移行し、インフラ管理の効率化・保守性向上を実現
- CI/CD パイプラインを整備し、デプロイ作業の属人化を解消

- データ分析基盤の構築と他部署・ユーザー向けデータ提供および施策提案
- 開発チームのコードレビューおよびインフラ領域を中心とした技術的意思決定・メンバー育成

#### 成果

- Backlog 運用刷新・会議体へのアイスブレイク導入など、心理的安全性の高い開発環境を整備
- 要件定義の精度向上により、**開発の手戻りを削減・開発リードタイムを平均 20% 短縮**

- インフラ構成の整理・CI/CD 整備により、**リリース作業工数の削減とデプロイの属人化解消**を実現
- BIツール導入によるデータ分析基盤の構築と、他部署への情報提供・施策提案への貢献
- 経験の浅いメンバーへの技術サポートを通じ、リリース後のトラブルにも迅速対応できるチーム体制を構築

## 自己PR

管理栄養士として医療現場で培った「人の話を深く聞き、本質的な課題を見つける力」と、エンジニア・PdMとして培った「技術的な実現可能性を踏まえた設計・推進力」を掛け合わせ、食品・農業分野を中心に新たな価値提供に挑戦しています。

現職では、PdM 兼エンジニアとしてプロダクトの企画・要件定義から設計・実装・運用まで一気通貫で携わり、チームの生産性向上や開発プロセスの改善をリードしてきました。特に、要件定義における認識齟齬の防止、インフラの属人化解消、CI/CDによるデプロイ自動化など、**技術とプロセス両面から組織の課題を解決**することに強みを持ちます。

また、DDD を用いた API リプレイスやデータ分析基盤の構築など、中長期を見据えたアーキテクチャ判断にも積極的に関与しており、上流工程への関与力を継続的に高めています。チームリーダーとしてメンバーの育成や心理的安全性の高い環境づくりにも取り組んでおり、技術力とマネジメント力を兼ね備えたエンジニアとして成長し続けています。
